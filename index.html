Going live with real EasyPost rates

This page ships with a matching backend — deploy it once, then flip the toggle above.

This HTML file can't safely call EasyPost directly — that would expose your API key to anyone who opens the page. It's built to work alongside a small serverless function (/api/quote) that holds the key server-side. You received this file inside a project folder with that function already written; deploy the whole folder to Vercel (free tier is fine):

  1. Install the Vercel CLI (npm i -g vercel) or use the Vercel dashboard's "Import Project."
  2. From the project folder, run vercel and follow the prompts to create the project.
  3. In the Vercel dashboard → Project Settings → Environment Variables, add EASYPOST_API_KEY with your real key (never in code, never in this chat).
  4. Redeploy with vercel --prod, then open the deployed URL and turn on "Use live EasyPost rates."

Full details are in the project's README.md. With the toggle off, this page keeps working standalone with the built-in estimate engine (dimensional divisor, zone tiers, fuel surcharge %, accessorial fees) — a ballpark for customer-facing quotes, not a binding rate.
